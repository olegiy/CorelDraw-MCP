# Этап 1: техническая проверка пройдена после уточнения Unicode

Работа выполнялась в `codex-like-ui-task-1` по плану
`.kilo/plans/1794339253999-csharp-worker-typed-corel-tools.md`.
Первоначальный блокер Unicode снят согласованным отказом до мутации.
Этапы 1–3 прошли технические проверки; базовый каталог этапа 4 проверяется
отдельно. Ниже сохранена история первоначальной диагностики этапа 1;
актуальные результаты находятся в `api-contract.json` и журнале плана.
По умолчанию остаётся прежний backend. Коммитов, установки продукта и
публикации не было; существующие изменения `webui` сохраняются.

Подготовлены C#-проект `net10.0-windows`, типизированное подключение к
`CorelDRAW.Application.27`, проверки версии и принадлежности STA-потоку,
сборка interop из зарегистрированной VGCore и отдельный live smoke.
SDK **10.0.404** загружен локально с разрешения пользователя; SHA-512 сверена
с официальными метаданными Microsoft. Системная установка SDK и PATH не
изменялись. Runtime теста: **.NET 10.0.15**.

Генератор проверил VGCore **27.2**, GUID
`95E23C91-BC5A-49F3-8CD1-1FC515597048`, `SYS_WIN64` и SHA-256 исходной type
library. `Tlbimp.exe` отсутствует; используется штатный `TypeLibConverter`
из .NET Framework, только при сборке. Получено предупреждение о
`IPDFSettingsInternal`: dual-интерфейс не наследует IDispatch. Этот интерфейс
не используется проверенными операциями; предупреждение сохранено в
`worker/generated/fingerprint.json`.

Live smoke на **CorelDRAW 27.2.0.135** проверил создание двух временных
документов, прямоугольников и текста, StaticID, Begin/EndCommandGroup,
ExportBitmap/Finish, PNG-файлы и закрытие только созданных документов.
Контрольный первый документ сохранил свои фигуры, координаты, текст и Dirty
при работе со вторым. Итоговые `cleanup_completed`,
`control_document_unchanged` и `active_document_restored` равны `true`.
Перед тестом пользовательских документов было **0**; восстановление
непустого пользовательского окружения ещё не подтверждено.

Блокирующий пример: `Проверка CorelDRAW 27 — Ёж 🦔` возвращается с повреждённым
последним символом. Ожидалась UTF-16-пара **55358, 56724**; CorelDRAW вернул
**32, 56724** — пробел и одиночный младший суррогат. JSON показывает его как
U+FFFD. Кириллица и тире сохранились. Ошибка воспроизведена для
CreateArtisticText/CreateArtisticTextWide, setters Text/WideText и явного
Segoe UI Emoji. Отдельные диагностики со штатной Corel interop-сборкой на
.NET 10 и через Windows PowerShell 5.1/.NET Framework дали тот же результат.
Эти диагностики не подключались как резервный backend.

Основной отчёт: [smoke.json](../artifacts/worker-smoke/ea38cf591e314df78fb530c388e0e989/smoke.json).
Точные CLR-сигнатуры, optional/default параметры, SDK 27 URLs и enum-значения:
[api-contract.json](api-contract.json).
Дополнительные диагностики и журнал решений сохранены в
`.superpowers/sdd/1794339253999-csharp-worker-typed-corel-tools/`.

На момент первоначальной диагностики запрашивалось решение: явно отклонять неподдерживаемые символы
до мутации или сохранить полную поддержку emoji как блокирующий критерий.
Решение и успешная повторная проверка приведены ниже. Право распространения
генерируемой interop-сборки также остаётся неподтверждённым; выпуск готового
пакета заблокирован отдельно от локальной разработки.

## Решение пользователя и повторная проверка

Пользователь согласовал отклонение неподдерживаемых символов до изменения
документа и продолжение. В `CorelText` добавлены проверки non-BMP, одиночных
суррогатов, NUL и ограничения 100000 UTF-16. Live smoke проверяет отказ для
emoji по неизменности Dirty/числа фигур, а затем допустимый BMP-текст.
Повторный запуск дал 15/15 прошедших C#-тестов, включая live. Актуальный
артефакт указан в `api-contract.json`; старые отчёты с ошибкой сохранены как
свидетельство ограничения CorelDRAW. Технический gate снят; этап 2 также
реализован (35/35 C#-тестов с live, 119/119 npm и отдельный реальный
межпроцессный тест TS↔C#). Права распространения interop остаются
неподтверждённым условием поставки; установка продукта не выполнялась.
