## Обнаруженные проблемы

### B01 — P0: существующая dist-сборка не запускает исполнителя

**Влияние:** блокирует получение document IDs, создание тестовых документов и весь функциональный прогон через Corel MCP.

**Доказательства:** текущий `dist/index.js` импортирует `PowerShellExecutor`; `dist/executor.js` запускает `../powershell/worker.ps1`, которого в рабочем дереве нет. Реальный запуск status завершается `unknown / EXECUTOR_LOST`; stderr сообщает отсутствие аргумента-файла. `src/index.ts`/`src/backend.ts` относятся к новому C# backend. Публикация server version `0.4.0` сама по себе не подтверждает актуальность собранного кода: версия читается из package.json.

**Шаги воспроизведения:** запустить сохранённый read-only probe; проверить handshake, tools/list, terminal status и stderr в отдельном run directory. Проверять приложение перед любым новым запуском; не повторять неизвестные мутации.

**Диагностический вывод:** доказано несоответствие собранной точки входа текущим исходникам и отсутствие требуемого ею скрипта. Ошибка CorelDRAW как приложения этим не доказана.

### B02 — P1: актуальный C# backend не подготовлен в текущем checkout

**Влияние:** простая замена точки входа/сборка TypeScript недостаточна для готового live-стенда.

**Факты:** ожидаемый `worker/publish/win-x64/CorelMcp.Worker.exe` отсутствует; `worker/generated/VGCore.Interop.dll` отсутствует; существующая сборка worker в проверенных bin-путях не найдена; системный SDK только `8.0.428`, тогда как `global.json` закрепляет `10.0.404` с `rollForward=disable`. Полный поиск установок за пределами проверенных каталогов не выполнялся, поэтому отсутствие SDK10 на всём компьютере не утверждается.

**Воспроизведение:** `Test-Path` указанных ожидаемых путей; `dotnet --list-sdks`; сопоставить с `global.json` и `src/csharp-executor.ts`.

### B03 — P1: нет подтверждённого полного интерфейса обхода меню

**Влияние:** даже работоспособные typed drawing tools не доказывают исполнение UI-команды с таким же смыслом; невозможна честная аттестация всего меню по API-аналогам.

**Факты:** фактически возвращённый MCP-каталог — 18 старых tools; операции полного перечисления/вызова menu command там нет. UIA не возвращает именованные Corel-пункты. Статическая инвентаризация неполна по именам и динамическому содержимому.

**Воспроизведение:** сопоставить `mcp-tools-list.json`, `final-window-tree.json`, снимки и `inventory-summary.json`.

### Не являются обнаруженными дефектами CorelDRAW

- Серые команды при отсутствии выделенных объектов, bitmap или истории Undo.
- Непроверенные облачные функции, печать, сканеры, внешние редакторы, ссылки и плагины.
- Ошибки начального диагностического клиента (путь импорта ESM) и синтаксиса CLI до исправления только временного тестового harness. Они не относятся к production-коду и не интерпретированы как ошибки Corel.
