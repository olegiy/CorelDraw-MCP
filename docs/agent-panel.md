# Панель агента CorelDRAW

Отдельная локальная панель использует существующий Corel MCP через stdio.
Python не вызывает COM: операции выполняются прежней цепочкой
TypeScript → PowerShell 5.1 STA → CorelDRAW 27.

## Статус

Разработка MVP продолжается. Non-live tests не подтверждают безопасность
живого VBA, совместимость всех экспортов и сохранность пользовательских
рисунков в реальном CorelDRAW. До отдельного live smoke не используйте панель
для единственных экземпляров рабочих документов.

## Требования

- Windows, обычная интерактивная сессия без elevation.
- Node.js 24 и Python 3.12.
- CorelDRAW 27 с VBA для реальных операций.
- Доступный Windows Credential Manager для модельного профиля.
- Модель с native OpenAI-compatible tool calls.

Панель слушает только `127.0.0.1:8878`. LAN, multi-user и одновременное
агентное управление через панель и Codex/Kilo не поддерживаются.

## Установка

Отдельный `scripts/Install-CorelAgent.ps1` создаёт `webhost/.venv`, устанавливает
Python зависимости по hash lockfile и собирает MCP/UI. Он не запускает
CorelDRAW и не меняет регистрацию Codex. Запуск установки требует отдельного
решения оператора. При разработке уже созданное repo-local окружение не
равнозначно установке в пользовательское окружение.

`scripts/Start-CorelAgent.ps1` запускает host в текущем терминале.
`-NoBrowser` не открывает окно и не печатает bootstrap-секрет.
Повторный Start обращается к проверенному владельцу через Windows-событие.
`scripts/Stop-CorelAgent.ps1` запрашивает штатную остановку, не убивает процесс
по имени, PID или порту. Терминал host нельзя принудительно закрывать во время
COM. Освобождение singleton происходит после drain транспорта.

## Доступ

Launcher выдаёт одноразовый bootstrap во fragment браузера. UI удаляет fragment
до обмена и передаёт секрет заголовком `X-Corel-Bootstrap`. Сессия использует
HttpOnly/SameSite=Strict cookie; CSRF хранится только в памяти UI. После
перезапуска host старая cookie недействительна. Проверяются точные Host/Origin
и Fetch Metadata. Публичного anonymous OpenAPI endpoint нет.

Эти меры не защищают от вредоносной программы того же Windows-пользователя.
Локальная история содержит пользовательские сообщения, VBA и Corel-отчёты;
она не является обезличенной технической диагностикой.

## Работа

Сначала явно обновите документы и выберите точный `document_id`.
`ActiveDocument` CorelDRAW и цель панели не взаимозаменяемы. Новая переписка
не закрывает рисунки. При смене сессии Corel старую цель нельзя восстанавливать
по имени или порядковому номеру.

«Только чтение» включено по умолчанию. Снятие флага даёт разрешение на обычные
изменения в рамках нового Run, но не постоянное разрешение VBA. Любой VBA
требует отдельного подтверждения полного кода. VBA имеет доступ ко всему
CorelDRAW и ОС, а не sandbox выбранного документа.

CDR открывается только после регистрации конкретного локального файла.
Новый Save As/export использует выбранный существующий output root и имя
`@output/файл`. UNC, traversal, ADS, device names и reparse/junction запрещены.
Существующий чужой файл требует явного overwrite и одноразового approval.
Изменение fingerprint аннулирует согласие. Проверка не блокирует атомарно
внешнее изменение во время нативного Save/Finish.

## Фон И Остановка

Закрытие вкладки уничтожает только SSE-подписку. Разрешённые шаги продолжаются
в host; опасный шаг ждёт approval. «Стоп» запрещает последующие шаги, но не
отменяет уже отправленный COM, не выполняет Undo и не гарантирует немедленного
освобождения CorelDRAW. Ранний Stop использует исходный `client_request_id`.

`timed_out` означает истечение срока наблюдения, не отмену операции.
`unknown` и неполный cleanup устанавливают safety barrier. Автоматический
repair/replay VBA не выполняется. Потеря HTTP-ответа разрешается чтением
`/requests/{id}`, а не новым ID команды.

## Хранилище И Recovery

Данные панели: `%LOCALAPPDATA%\CorelDrawAgent`.
При запуске проверяются owner и защищённый ACL каталога: разрешения получает
только текущий Windows-пользователь. Существующий каталог с непроверенными
правами не исправляется молча; запуск останавливается до операторской проверки.
Corel jobs остаются в `%LOCALAPPDATA%\CorelDrawMcp\runs`.
API keys хранятся только в Credential Manager namespace `coreldraw_agent`;
недоступность vault не включает fallback в JSON/env.

Не удаляйте `runtime.json` и `mcp-owner.json`, чтобы обойти неизвестного
владельца. Crash и незавершённый прежний Job требуют проверки process identity
и исходного отчёта. Recovery не возобновляет модельный план или старые approvals.
Операторский review записывает отдельное наблюдение и не переписывает старый
исход. Непроверяемые предпосылки нельзя объявлять выполненными автоматически.

## Проверки

`scripts/Verify-CorelAgent.ps1` запускает MCP tests/contracts, Python non-live
tests/ruff, offline OpenAPI drift, UI types/build/Playwright.
Реальные CorelDRAW tests не запускаются этой командой. Live smoke требует
отдельного opt-in, временных документов и before/after inventory. После него
удаляются только собственные диагностические `CorelMcp_*` GMS; сторонние
проекты, рисунки и отчёты не затрагиваются.
