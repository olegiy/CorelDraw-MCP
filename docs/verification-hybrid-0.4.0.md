# Проверка гибридного исполнителя 0.4.0

Рабочее дерево: `codex-like-ui-task-1`. Дата испытаний: 13 ноября 2026. Это отчёт проверки исходников и локального developer-комплекта; установка и публикация не выполнялись. Финальная приёмка пока продолжается.

## Реализовано

C# сохраняет один STA worker, mutex, проверку целей, состояния документа, журнал задач и обработку partial/unknown. Готовый собственный GMS исполняет фиксированные пакетные операции. Произвольный VBA, имена макросов и COM dispatch через MCP недоступны. Обычный запуск не компилирует VBA и не обращается к VBE. Общий runtime не выгружается при завершении отдельного клиента.

Каталог содержит 39 инструментов: прежние 37 и строгие `corel_create_batch` / `corel_update_batch`. Для них нужны явный режим `hybrid`, до 1000 элементов, до 100000 UTF-16 единиц текста и ограниченный размер сообщения. Пакет проверяется целиком до изменения документа. Существующие подходящие пакеты создания, стиля, перемещения, копирования, правок текста и преобразования текста используют подготовленные маршруты. Геометрия извлекается из приватной копии; исходные ID и геометрические доказательства фиксируются до клонирования.

Модуль `CorelMcp_Runtime_v1_9b5348678d96`, версия `0.4.0`:

- SHA256 исходников: `9b5348678d96ccb92bedc28e2ab84894b7b4998d7ca145a8b1c64d168dbd9157`.
- SHA256 GMS: `126b41afa31e908d1b0008b87cfb18812ade20502fbb52408837b9ea5654d0f9`.

## Живые проверки

Сохранены проверки 1000 цветов с округлением RGB и поворотами, кириллицы и смешанного форматирования, фактических шрифтов, copy-major порядка дубликатов, ID после преобразования текста, запретов для заблокированных целей и неверных документов/слоёв, мм/дюймов и смещённого начала координат. Контролируемая частичная ошибка возвращает подтверждённые ID; потеря ответа после изменения блокирует новые мутации без повтора и автоматического Undo.

MCP smoke выполнил 100 нативных операций, проверил идемпотентность request_id, прочитал все 1000 цветов/центров/углов атласа, сохранил CDR и декодировал PNG. Отчёт: `artifacts/integration-hybrid/b87ff75f-83a0-4ff4-bcb8-93ee5e2f53bd/verification.json`. Поздние изменения геометрии требуют отдельной итоговой регрессии; этот результат не подменяет её.

Выявленные и исправленные дефекты включают ложные deleted-ID при частичном update, модальное окно при отсутствующем шрифте, противоречивые bounds непечатаемого слоя, зависание чтения исходного StaticID после клонирования (H11), переключение активного документа при освобождении экспортного фильтра (H12) и неверный execution_engine при ошибке native geometry. Диагностика и воспроизведения сохранены в `.superpowers/sdd/2026-11-13-corel-hybrid-runtime/`.

H11: после исправления прогрев и три пары geometry100 прошли без зависания. Каждый результат и неизменность источника проверены отдельно. Медиана полного публичного измерения — C# **29,27 с**, hybrid **3,90 с** (около **7,5×**). Отчёт: `artifacts/hybrid-benchmark/a571a070-bb14-4166-82ee-cd3f1c10b73a/benchmark.json`. В отчёте указан SHA сборки; последующее изменение касается маркировки маршрута ошибки.

Указанные предыдущие замеры выполнены на модуле 2afd73d96b26 до исправлений независимого review; текущий модуль требует повторных проверок. Финальная сравнительная серия остальных операций выполняется. Прогрев исключается из статистики; чередуются режимы, используются три медленных или пять быстрых повторов. Сценарий плашек включает создание, стиль, поворот и сохранение. Подготовка fixtures для геометрии, стиля, перемещения, копирования, PNG и инспекции исключена из timing и записана отдельно. Кооперативная остановка после пяти минут сохраняет частичный CDR; неполную пару нельзя выдавать за завершённый замер.

## Ограничения приёмки

Режим по умолчанию остаётся `csharp`. Чистый перезапуск CorelDRAW не выполнялся: сторонние защищённые проекты BDMacros и JH_SelectSame имеют несохранённое состояние. Их сохранение, выгрузка или отбрасывание изменений не выполнялись. Двадцать привязок и перезапуски worker проверялись отдельно и не заменяют новый процесс Corel.

Права на распространение VGCore.Interop.dll не подтверждены. Проверка установщика и упаковщика сохраняет этот блокирующий gate. Наличие локально собранного GMS не является разрешением на выпуск всего пакета.

Текстуры: проверенный запрос preset не совпал с фактической identity Corel, поэтому публичного texture-инструмента нет. Full-color pattern из собственного векторного CDR при SVG-экспорте дал связанные растровые файлы: результат сообщает предупреждение и список assets; SVG нужно переносить вместе с ними. Отсутствие распознанного raster-признака означает unknown fidelity.

Это не полная проверка всех вариантов 47 исследовательских групп. Mesh, spot/overprint и часть преобразований сложных эффектов остаются незакрытыми возможностями. Неподдерживаемые символы вне BMP отклоняются до изменения текста; Corel в проверенной версии повреждает такие символы. WideText удаляет LF, в том числе в CRLF оставляет CR; это наблюдалось в обоих путях.

## Дополнительная проверка после независимого review

После исправления учёта незавершённых мутаций и cleanup пересобран GMS 9b5348678d96. Семь живых тестов ошибок и частичной замены прошли; повторно прошли npm test (150, пропущено 2), dotnet test (166, пропущено 52 live), check:contracts и пять штатных MCP integration-сценариев. Длительный hybrid smoke также завершён успешно. Пропущенные в обычном .NET прогоне живые тесты не следует считать пройденными только по этому счётчику.

Макет 100 этикеток на десяти страницах прошёл отдельный live-тест с независимым чтением шрифтов всех этикеток и анализом векторного содержимого каждой страницы PDF: `artifacts/worker-drawing/5a7fc01a78ee4514a47594e7f670b4ce/showcase.json`.

В каждом прежнем повторе текстового benchmark независимо проверялся текст каждой цели; шрифт и геометрия каждого повторения отдельно не проверялись. Поэтому полная корректность каждого текстового benchmark-повтора пока не подтверждена. Самостоятельный тест этикеток не заменяет эту проверку.

На модуле 9b5348678d96 повторены измерения (прогрев и три зачётных повтора): копирование 100 объектов — медиана C# 5,97 с, hybrid 1,68 с; геометрия 100 объектов — 29,08 с и 3,76 с; создание и сохранение 20 текстов — 13,17 с и 1,49 с. Для 1000 плашек hybrid — 5,42 / 5,42 / 5,44 с; C# остановлен между командами через 302,86 с и частичный CDR сохранён. Полной пары 1000 нет. Отчёт: `artifacts/hybrid-benchmark/516ceacd-6794-4efc-bcad-655b50c26b67/benchmark.json`.

Готовый GMS прошёл 20 handshake без VBE-вызовов и без изменения открытых документов. В Corel открыты два собственных показательных макета; снимок подтверждает видимую первую страницу этикеток, атлас доступен на соседней вкладке. Свежий процесс Corel и полная проверка шрифта/геометрии каждого текстового benchmark-повтора остаются незакрытыми.
