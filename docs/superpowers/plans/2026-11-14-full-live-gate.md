## Ограничения

- Не удалять, не подделывать и не переписывать исторические reports. Не выставлять `applied=false` без доказательств. Не переигрывать старые jobs.
- Не подменять установленную историю пустой БД и не исключать проблемные roots ради успешного admission.
- Не ослаблять exact-path/name/hash/dirty-проверки runtime и настройки безопасности VBA.
- Не удалять общий runtime и сторонние GMS как диагностический мусор.
- Не вызывать `Application.Quit`; при необходимом перезапуске — отдельное согласование и штатное закрытие пользователем после сохранения документов.
- Все COM-операции сериализованы под общим mutex. Не выполнять `npm test` одновременно с live COM suites.
- Не убивать worker и не освобождать слот при таймауте/unknown. Сначала установить фактический исход; не закрывать fixture с неопределённой выполняющейся операцией.
- Пользовательские документы не сохранять, не редактировать и не закрывать. Изменять и закрывать только документы, доказанно созданные конкретным тестом.
- Коммиты, push, установка, публикация и смена default backend не входят в план.
- Не создавать дополнительные Agent Manager sessions/worktrees без отдельного запроса.

## Стоп-условия и согласования

Немедленная остановка дальнейших мутаций при неожиданном `unknown`, таймауте с живым worker, неподтверждённом partial, изменении чужого документа, неизвестном владельце GMS или провале cleanup. Сохранить доказательства; не retry, не Undo, не kill. Известный тестовый fault обрабатывается только заранее проверенным сценарием своей fixture.

Перед исполнением требуется подтвердить целевую ветку. Перед перезапуском CorelDRAW, выгрузкой уже существовавшего GMS или изменением recovery-контракта требуется отдельное решение. Согласование плана не заменяет эти подтверждения.
