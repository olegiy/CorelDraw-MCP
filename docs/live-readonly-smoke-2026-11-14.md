## Ошибка превью

Воспроизведение:

1. Подключить отдельный сервер в csharp или hybrid к открытому пустому документу.
2. Получить актуальный `document_id` через `corel_status`.
3. Отправить `corel_preview({document_id, page_index:1, target:'page', max_size:600, deadline_seconds:30})`.
4. Дождаться terminal report через `corel_get_job`.

Наблюдение в обоих режимах:

```text
status: failed
error.code: COM_ERROR
error.stage: exporting
error.number: -2147467259 (0x80004005)
error.source: VGCore.Interop
error.message: Unexpected HRESULT has been returned from a call to a COM component.
error.applied: false
cleanup.completed: true
```

Влияние: нельзя получить PNG-превью для данного пустого документа; MCP image и корректность PNG в этом прогоне не проверены. Ошибка не локализована до первопричины; пустое содержимое — условие воспроизведения, а не доказанная причина. Общий сбой гибридного механизма этим не доказан: ошибка одинаковая, preview использует общий экспортный путь.

Рекомендуемый следующий диагностический шаг (не выполнен): после разрешения исторического admission подготовить собственные пустой и непустой fixtures и сравнить preview с точной диагностикой вызова экспортного фильтра. Приоритет P2, если проблема ограничена пустой страницей; повысить до P1, если воспроизводится на непустой. Критерий исправления: документированное корректное поведение пустого случая, PNG/MCP image для непустого случая, полное сохранение состояния, регрессия в обоих режимах.

Исправления production-кода и повторные мутации не выполнялись.
