# Архивный отчёт проверки версии 0.1.0

Актуальный incremental-прогон описан в [verification-0.2.0.md](verification-0.2.0.md).
`npm run test:integration` теперь последовательно выполняет основной harness
и `test/integration-recipes.mjs`, включая отрицательные recipe/preview сценарии.
Исторические результаты ниже не являются доказательством новой реализации.

Проверено 3 ноября 2026 года на Windows с Node.js 24.18.1, Windows PowerShell 5.1.26100.9711 (STA) и CorelDRAW 27.2.0.135 с VBA.

## Автоматические проверки

Архивный прогон до расширения интерфейса: `npm test` **13 из 13**. Проверены настоящий MCP stdio handshake и схемы базовых инструментов, валидация входов, Unicode и пути с пробелами, сохранение/повтор request_id и конфликт аргументов, тайм-аут с последующим результатом, BUSY, межпроцессный Windows mutex, завершение текущего задания при закрытии транспорта, потерянный владелец, ошибки записи артефактов, некорректные сообщения исполнителя, точные типы JSON и выдача изображения preview.

`npm run test:integration`: **19 из 19** сценариев в установленном CorelDRAW. Проверены:

- отдельные идентификаторы документов и выбор целевого документа при другом активном;
- создание, сохранение, закрытие и открытие CDR с кириллицей/пробелами, защита от перезаписи и потери изменений;
- PNG/SVG страницы и выделения, PDF страницы и документа;
- preview 600 × 480 с полями страницы и проверкой пикселей в ожидаемых координатах;
- компиляция UTF-8 .bas, выполнение с JSON, примеры создания и перемещения геометрии;
- runtime error 555 с сохранением GMS; независимое сравнение Optimization, EventsEnabled, активного документа, единиц и PreserveSelection до и после ошибки;
- массивы, скаляры и null без преобразования типов; сохранение GMS при пустом/некорректном JSON;
- три последовательные полные компиляции с ошибкой в невызываемой процедуре: M_Invalid, строка 3, включая наличие нескольких ранее сохранённых ошибочных проектов;
- устаревшие document_id после закрытия документа и после переподключения исполнителя.

Полный успешный отчёт и артефакты этого прогона:

```text
%LOCALAPPDATA%\CorelDrawMcp-integration-MpqqXP\verification.json
%LOCALAPPDATA%\CorelDrawMcp-integration-MpqqXP\runs\
```

Тесты закрыли собственные временные документы. Диагностические GMS от намеренных ошибок оставлены в CorelDRAW и каталогах запуска согласно контракту сервера.

## Установка и новая сессия Codex

Проверены повторная установка, удаление и повторная установка. После цикла пользовательский config.toml совпал побайтно с конфигурацией до проверки. Итоговая регистрация coreldraw включена; глобальный скилл — junction на skills/coreldraw-automation этого проекта. Локальный отчёт: artifacts/installation-verification.json.

В отдельной новой сессии `codex exec --ephemeral` обнаружен и прочитан глобальный скилл. Зарегистрированные MCP-инструменты corel_status и corel_get_job вернули успешное задание, версию 27.2.0.135, доступный VBA/компилятор и 0 открытых документов. Подтверждён STA PowerShell 5.1, события включены, оптимизация выключена. Сессия не изменяла документы. Локальные доказательства: artifacts/codex-events.jsonl и artifacts/codex-verification.txt; job_id: 9b2257cf-33ad-43bc-a635-3db3444b6543.

Существующие предупреждения Codex о других глобальных компонентах (node_repl, значки и legacy_notify) не препятствовали вызовам coreldraw; их конфигурация не изменялась.

Валидатор skill-creator: **Skill is valid!**. PowerShell-файлы проходят синтаксический разбор; TypeScript проходит сборку. Сигнатуры CorelDRAW сверены через Context7 с API 27.

## Границы проверки

Проверена указанная локальная версия CorelDRAW. Диалоги сторонних фильтров, заблокированные/повреждённые CDR и другие сборки приложения могут вести себя иначе. Тайм-аут и потеря владельца проверяются синтетическим исполнителем; настоящее зависание CorelDRAW намеренно не создавалось. Полностью безоконный запуск, классы и формы VBA в эту версию не входят.
