# Готовые операции

Единственный исполнитель — C# для CorelDRAW 27, .NET 10 x64. Все параметры проходят строгие MCP JSON Schema и типизированные DTO. Неизвестные поля и смешение вариантов отклоняются. В новых мутациях обязательны request_id, document_id и page_index; document_id не заменяется текущим окном.

Идентификаторы страниц/слоёв непрозрачны и принадлежат сеансу; StaticID стабилен только в течение жизни фигуры. Не выбирайте слой по первому индексу: проверяйте is_special_layer. Родитель и его потомок вместе в одной мутации запрещены, чтобы исключить двойное действие.

| Группа | Операции и ограничения |
| --- | --- |
| Пакеты hybrid | create_batch: rectangle/ellipse/line/artistic_text, уникальный item_key; update_batch: уникальный StaticID, стиль затем одна трансформация. До 1000 элементов, текст суммарно 100000 UTF-16, payload 1 МиБ. Только простые цели без групп/bitmap/live effects/PowerClip. Пакетные заливки — только none/uniform; fountain отклоняется до маршрутизации (BATCH_FILL_UNSUPPORTED), применяется через style. |
| Геометрия | create_shapes: rectangle/ellipse/line; до 100 входных элементов. transform: move/scale/rotate/flip с явным anchor для масштаба/поворота. duplicate: до 1000 новых объектов с учётом групп. |
| Заливки и эффекты | style fill kind fountain: type linear/radial/conical/square, 2–16 стопов (крайние 0/100, промежуточные 1–99 строго возрастают), angle_deg только linear/conical/square, center_offset_*_percent — проценты без конвертации. set_transparency: none/uniform/fountain, applied_to/merge_mode обязательны для применения и игнорируются для none, freeze после применения. apply_drop_shadow: одиночные фигуры и текст, снятие kind none. |
| Организация | Слои по layer_id, имена могут совпадать. group/ungroup снимает один уровень. Boolean использует точные left/right ID и явные keep flags; LEFT.Trim(RIGHT) вырезает RIGHT. Convert возвращает id_mappings. |
| Текст | Artistic/paragraph, только установленный явный шрифт. Буквальная ordinal/non-overlapping замена сохраняет форматирование вне совпадений. Форматирование — всей истории. CRLF нативно нормализуется в CR; фактический текст возвращается. |
| Кривые | inspect с ограниченной выдачей и полным revision; одна edit action с индексами с единицы. Insertion сохраняет форму кубического сегмента. Join только концов в пределах явного tolerance_mm; закрытый контур минимум 3 узла. |
| Контроль | find/inspect_curve/preflight read-only. Неизвестный тип/effect/лимит означает unknown или явный отказ, не passed. |
| Раскладка | Align использует геометрические bounds; grid/layout учитывают outline. Dry_run не открывает undo group. Apply требует тот же порядок ID, параметры и актуальный revision. |
| Сборка | SVG/PDF/PNG/JPEG до 256 МиБ, локальный путь без reparse/junction/network. SHA-256/размер проверяются при freeze. PDF с паролем не открывается через диалог. Импорт сначала в собственный private документ, перенос через собственный CDR с provenance markers. |
| Страницы/PowerClip | Add/resize точной страницы без удаления/перестановки. PowerClip place/extract поддерживает bitmap и вложенные контейнеры, запрещает циклы, не масштабирует содержимое; extract снимает один уровень. |

Новые текстовые значения вне BMP, NUL и одиночные суррогаты отклоняются до BeginCommandGroup. В SVG text/tspan это проверяется до native import, для остальных фильтров — в собственной private копии до изменения целевого документа. Частные native paths длиннее 259 UTF-16 дают NATIVE_PATH_TOO_LONG.

Transform/duplicate/group/move-to-layer и align/grid/layout принимают также bitmap и смешанные группы без live effects/PowerClip. Boolean/convert/style остаются векторными; редактирование пикселей, трассировка и измерение PowerClip не входят. Цели с прозрачностью, тенями и другими live-эффектами не получают style/convert/boolean/scale/layout/update_batch: существующий effects-барьер не расширен. Bitmap revision включает матрицу и полный CropEnvelope; для прямоугольного bitmap без crop — наблюдаемый frame. Locked слой/предок, special layer, неподдержанный тип и повреждённая цель отклоняются до мутации.

Для сборки растровых наклеек duplicate/grid, move/rotate, group/ungroup и move-to-layer также сохраняют обычную и градиентную прозрачность отдельных поддержанных объектов и потомков группы. Допускается единственный эффект cdrLens, представляющий незамороженную cdrUniformTransparency/cdrFountainTransparency без отдельной точки обзора. Эффекты самой группы и другие эффекты не допускаются; scale/flip, align/shelf-layout и векторные операции не получают это разрешение. Bitmap и объекты с прозрачностью остаются на C#-пути даже при execution_mode=hybrid и большом числе копий; изображение не растрируется повторно, эффекты не удаляются.

Fountain-заливка применяется через ApplyFountainFill первым/последним стопом и Colors.Add для промежуточных. Отчёт и inspect возвращают наблюдаемые значения, а не запрошенные: Corel нормализует EdgePad для linear и square с ненулевым углом (0→15 и 20→29 при 45° на 40×20 мм; при угле 0 возвращается точно; conical не затронут), многостоповые градиенты читаются как blend_type=custom, наблюдаемые умолчания — steps 256, edge_pad 0, mid_point 50, blend direct, spread pad, smooth_blend false; Colors.Item индексируется с нуля (0..Count-1), в отличие от 1-based IVGShapes. Прозрачность применяется в COM-порядке Apply → AppliedTo/MergeMode → Freeze: свойства AppliedTo/MergeMode существуют только после Apply* и недоступны раньше. Радиальная fountain-прозрачность ориентирована инвертированно относительно fountain-заливки: start действует от края, end — к центру (live-probe T9: artifacts/probe-transparency.mjs, artifacts/probe-runs, Corel 27.2); start/end выбираются с учётом этой ориентации. Группа допускается для прозрачности только если все потомки поддержаны; frozen, locked, special layer, bitmap, PowerClip и не-lens эффекты отклоняются до мутации (отказ special layer покрыт non-live тестом — общая ветка Leaves с locked/bitmap). Lens на самом узле группы не валидируется: по букве контракта проверяются только потомки, как у style.

Тень применяется к одиночным векторным фигурам (типы 1/2/3/4) и тексту (6); группы — limitation v1. Цель не оборачивается: StaticID, тип и геометрия сохраняются, эффект attaches к цели, рядом создаётся sibling-группа тени (группа + один потомок). Отчёт возвращает id_mappings {source_static_id, result_static_ids:[target, group, child]} и фактические created/deleted; снятие — kind none через Shape.ClearEffect(cdrDropShadow), возвращает [target]. Повторная тень к уже затенённой цели, группы, bitmap, locked, PowerClip и существующие эффекты отклоняются до мутации. После наложения тени цель отказывает другим мутациям через существующий effects-барьер: allowTransparency не расширен, сначала снимите тень kind none. fade запрещён для flat; смещения offset_x_mm/offset_y_mm — мм. Mesh-заливка — non-goal с доказательством: в dispatch API 27 typelib нет Mesh-интерфейсов и членов (только enum cdrMeshFillShape=20); аппроксимация — наслоенные fountain-прозрачности и мозаика uniform-фигур.

При UNSUPPORTED_SHAPE смотрите StaticID в сообщении и `shapes[].effects` в corel_inspect_document: count, items с типами effect/lens/transparency и complete. Complete относится к ограниченному списку наблюдаемых эффектов, не к визуальной эквивалентности или полному описанию всех параметров. При неполном чтении выдаётся complete=false; наличие JPEG/PNG само по себе не является причиной запрета.

Import возвращает `import_diagnostics`: фактические шрифты текста, доступность семейств по каталогу Windows, число наблюдаемых native effects и неподдержанные типы. Сходство с источником, соответствие исходных шрифтов и эффектов имеют статус `unknown`: native-фильтр мог заменить/растрировать/преобразовать их. Нужна визуальная проверка preview; наличие установленного шрифта не доказывает отсутствие подмены.

Успех оценивается по фактическим данным: affected/created/deleted_static_ids, items, bounds, revision и cleanup. При частичном исходе известные ID сохраняются; неизвестная полнота не заменяется пустым успешным результатом. Не запускайте повтор, undo, исправление или другой backend автоматически.
