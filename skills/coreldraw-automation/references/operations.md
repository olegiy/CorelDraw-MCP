# Готовые операции

Единственный исполнитель — C# для CorelDRAW 27, .NET 10 x64. Все параметры проходят строгие MCP JSON Schema и типизированные DTO. Неизвестные поля и смешение вариантов отклоняются. В новых мутациях обязательны request_id, document_id и page_index; document_id не заменяется текущим окном.

Идентификаторы страниц/слоёв непрозрачны и принадлежат сеансу; StaticID стабилен только в течение жизни фигуры. Не выбирайте слой по первому индексу: проверяйте is_special_layer. Родитель и его потомок вместе в одной мутации запрещены, чтобы исключить двойное действие.

| Группа | Операции и ограничения |
| --- | --- |
| Пакеты hybrid | create_batch: rectangle/ellipse/line/artistic_text, уникальный item_key; update_batch: уникальный StaticID, стиль затем одна трансформация. До 1000 элементов, текст суммарно 100000 UTF-16, payload 1 МиБ. Только простые цели без групп/bitmap/live effects/PowerClip. |
| Геометрия | create_shapes: rectangle/ellipse/line; до 100 входных элементов. transform: move/scale/rotate/flip с явным anchor для масштаба/поворота. duplicate: до 1000 новых объектов с учётом групп. |
| Организация | Слои по layer_id, имена могут совпадать. group/ungroup снимает один уровень. Boolean использует точные left/right ID и явные keep flags; LEFT.Trim(RIGHT) вырезает RIGHT. Convert возвращает id_mappings. |
| Текст | Artistic/paragraph, только установленный явный шрифт. Буквальная ordinal/non-overlapping замена сохраняет форматирование вне совпадений. Форматирование — всей истории. CRLF нативно нормализуется в CR; фактический текст возвращается. |
| Кривые | inspect с ограниченной выдачей и полным revision; одна edit action с индексами с единицы. Insertion сохраняет форму кубического сегмента. Join только концов в пределах явного tolerance_mm; закрытый контур минимум 3 узла. |
| Контроль | find/inspect_curve/preflight read-only. Неизвестный тип/effect/лимит означает unknown или явный отказ, не passed. |
| Раскладка | Align использует геометрические bounds; grid/layout учитывают outline. Dry_run не открывает undo group. Apply требует тот же порядок ID, параметры и актуальный revision. |
| Сборка | SVG/PDF/PNG/JPEG до 256 МиБ, локальный путь без reparse/junction/network. SHA-256/размер проверяются при freeze. PDF с паролем не открывается через диалог. Импорт сначала в собственный private документ, перенос через собственный CDR с provenance markers. |
| Страницы/PowerClip | Add/resize точной страницы без удаления/перестановки. PowerClip place/extract поддерживает bitmap и вложенные контейнеры, запрещает циклы, не масштабирует содержимое; extract снимает один уровень. |

Новые текстовые значения вне BMP, NUL и одиночные суррогаты отклоняются до BeginCommandGroup. В SVG text/tspan это проверяется до native import, для остальных фильтров — в собственной private копии до изменения целевого документа. Частные native paths длиннее 259 UTF-16 дают NATIVE_PATH_TOO_LONG.

Transform/duplicate/group/move-to-layer и align/grid/layout принимают также bitmap и смешанные группы без live effects/PowerClip. Boolean/convert/style остаются векторными; редактирование пикселей, трассировка и измерение PowerClip не входят. Bitmap revision включает матрицу и полный CropEnvelope; для прямоугольного bitmap без crop — наблюдаемый frame. Locked слой/предок, special layer, неподдержанный тип и повреждённая цель отклоняются до мутации.

Import возвращает `import_diagnostics`: фактические шрифты текста, доступность семейств по каталогу Windows, число наблюдаемых native effects и неподдержанные типы. Сходство с источником, соответствие исходных шрифтов и эффектов имеют статус `unknown`: native-фильтр мог заменить/растрировать/преобразовать их. Нужна визуальная проверка preview; наличие установленного шрифта не доказывает отсутствие подмены.

Успех оценивается по фактическим данным: affected/created/deleted_static_ids, items, bounds, revision и cleanup. При частичном исходе известные ID сохраняются; неизвестная полнота не заменяется пустым успешным результатом. Не запускайте повтор, undo, исправление или другой backend автоматически.
