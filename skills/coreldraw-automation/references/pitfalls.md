# Ограничения и восстановление

- Только CorelDRAW 27, Windows x64, интерактивная пользовательская сессия. Не вызывайте Application.Quit и не завершайте процессы CorelDRAW для освобождения mutex.
- Один COM job, включая cleanup. Polling не обращается к COM. Истечение deadline не отменяет вызов; второй job получает BUSY, пока прежний реально не закончен.
- Document/page/layer IDs принадлежат сеансу, StaticID — жизни фигуры. Закрытая/заменённая цель даёт stale/not found, без поиска по имени или индексу. Поддерживаются только явно описанные типы и операции.
- Read-only не должен менять исходный документ. Измерение/экспорт и текстовый geometry fingerprint используют собственную проверенную копию; исходный текст в кривые не превращается. Сохранение Dirty не подменяется принудительным сбросом.
- BeginCommandGroup может сам изменить Dirty. Ошибка после Begin не доказывает applied:false; известные изменения/IDs возвращаются отдельно, undo/replay не выполняется.
- Неподдерживаемый non-BMP/NUL/UTF-16 текст отклоняется до мутации. Отсутствующий шрифт не подменяется автоматически. Mixed formatting вне буквальных замен сохраняется; CRLF Corel нормализует в CR.
- SVG с внешними ссылками, активным содержимым, DTD и неподдержанными CSS escapes не передаётся фильтру. PDF с паролем, отсутствующая выбранная страница и длинный private native path — явные отказы. Native-фильтры не являются сетевым sandbox.
- Preflight unknown не означает passed; гарантий пригодности оборудования, ICC, OCR, трассировки и фигурного nesting нет. Layout и измерение не применяются к live effects/PowerClip; PowerClip обслуживается отдельным инструментом.
- Shape.Effects включает обычную прозрачность как cdrLens: не объявляйте наклейку неподдержанной только по ненулевому count и не удаляйте её эффекты автоматически. Подтверждённое исключение для duplicate/grid, move/rotate, group/ungroup и move-to-layer описано в operations.md; настоящий lens, frozen/viewpoint, эффекты группы и unknown по-прежнему запрещены. Не создавайте synthetic UseViewPoint=true в общем live-прогоне: CorelDRAW 27.2 может аварийно завершиться при закрытии такой тестовой фигуры; условие запрета проверяется без COM.
- Fountain: многостоповые градиенты применяются через Colors.Add промежуточных стопов; крайние стопы фиксированы 0/100, промежуточные 1–99 строго возрастают и уникальны. Read-back отражает наблюдаемое, а не запрошенное: Corel нормализует EdgePad для linear и square с ненулевым углом (0→15 и 20→29 при 45° на 40×20 мм; 7→19 при 30°; при угле 0 значение возвращается точно; conical не затронут), многостоповые градиенты читаются как blend_type=custom даже при запрошенном direct, наблюдаемые умолчания steps=256/edge_pad=0/mid_point=50/blend=direct/spread=pad/smooth_blend=false. Colors.Item индексируется с нуля (0..Count-1), в отличие от 1-based IVGShapes. center_offset_x/center_offset_y — проценты размеров объекта, передаются как есть, не мм.
- Прозрачность: свойства AppliedTo/MergeMode существуют только после Apply* (COM-ошибка при установке до применения); порядок — Apply → AppliedTo/MergeMode → Freeze. Для kind uniform/fountain обязательны applied_to и merge_mode; для kind none они необязательны, игнорируются и по умолчанию fill/normal. Группа допускается только если все потомки поддержаны; frozen, locked, special layer, bitmap, PowerClip и не-lens эффекты отклоняются до мутации. Отказ special layer покрыт non-live тестом (общая ветка Leaves с locked/bitmap). Lens на самом узле группы не валидируется: по букве контракта проверяются только потомки, как у style. Радиальная fountain-прозрачность ориентирована инвертированно относительно fountain-заливки: start действует от края, end — к центру (live-probe T9: artifacts/probe-transparency.mjs, artifacts/probe-runs, Corel 27.2); выбирайте start/end с учётом этой ориентации.
- Тень: цель не оборачивается — StaticID, тип и геометрия сохраняются, эффект attaches к цели, рядом создаётся sibling-группа (группа + один потомок); id_mappings = {source_static_id, result_static_ids:[target, group, child]}, снятие kind none (Shape.ClearEffect(cdrDropShadow)) возвращает [target]. Цели — одиночные векторные фигуры 1/2/3/4 и текст 6; группы — limitation v1. Повторная тень, bitmap, locked, PowerClip и существующие эффекты отклоняются до мутации. Затенённая цель затем отказывает другим мутациям существующим effects-барьером (style/convert/boolean/scale/layout/update_batch; allowTransparency не расширен) — сначала снимите тень kind none. fade запрещён с flat; смещения — мм. SVG-экспорт растрирует тень: Corel выносит её во внешнюю растровую зависимость папки _Images рядом с файлом (проверено в artifacts/gamepad-logitech-native.svg), самодостаточный SVG не гарантируется.
- Mesh-заливка — non-goal с доказательством: в dispatch API 27 typelib нет Mesh-интерфейсов и членов (только enum cdrMeshFillShape=20); аппроксимируйте наслоенными fountain-прозрачностями и мозаикой uniform-фигур. Fountain в пакетах hybrid отклоняется до маршрутизации (BATCH_FILL_UNSUPPORTED); сами fountain/прозрачность/тень остаются на C#-пути при любом объёме.
- Если cleanup временного документа/слоя не подтверждён, точный ID сохраняется, completed=true не выдаётся. Не удаляйте неизвестные объекты, чужие GMS или пользовательские рисунки.
- Исторические unknown/retained GMS не разрешаются новым кодом/VBE. До обновления используйте прежний релиз/оператора для подтверждения исхода; pre-upgrade проверка ничего не повторяет и не стирает. Старые отчёты и safety barrier сохраняются.
- Save As/export заменяет назначение автоматически. Export публикуется через промежуточный файл; нативный SaveAs не обещает атомарности. Отчёты и артефакты могут содержать пользовательские данные; краткая диагностика выдаёт только allowlist полей.
