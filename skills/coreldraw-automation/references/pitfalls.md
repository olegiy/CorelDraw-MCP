# Ограничения и восстановление

- Только CorelDRAW 27, Windows x64, интерактивная пользовательская сессия. Не вызывайте Application.Quit и не завершайте процессы CorelDRAW для освобождения mutex.
- Один COM job, включая cleanup. Polling не обращается к COM. Истечение deadline не отменяет вызов; второй job получает BUSY, пока прежний реально не закончен.
- Document/page/layer IDs принадлежат сеансу, StaticID — жизни фигуры. Закрытая/заменённая цель даёт stale/not found, без поиска по имени или индексу. Поддерживаются только явно описанные типы и операции.
- Read-only не должен менять исходный документ. Измерение/экспорт и текстовый geometry fingerprint используют собственную проверенную копию; исходный текст в кривые не превращается. Сохранение Dirty не подменяется принудительным сбросом.
- BeginCommandGroup может сам изменить Dirty. Ошибка после Begin не доказывает applied:false; известные изменения/IDs возвращаются отдельно, undo/replay не выполняется.
- Неподдерживаемый non-BMP/NUL/UTF-16 текст отклоняется до мутации. Отсутствующий шрифт не подменяется автоматически. Mixed formatting вне буквальных замен сохраняется; CRLF Corel нормализует в CR.
- SVG с внешними ссылками, активным содержимым, DTD и неподдержанными CSS escapes не передаётся фильтру. PDF с паролем, отсутствующая выбранная страница и длинный private native path — явные отказы. Native-фильтры не являются сетевым sandbox.
- Preflight unknown не означает passed; гарантий пригодности оборудования, ICC, OCR, трассировки и фигурного nesting нет. Layout и измерение не применяются к live effects/PowerClip; PowerClip обслуживается отдельным инструментом.
- Если cleanup временного документа/слоя не подтверждён, точный ID сохраняется, completed=true не выдаётся. Не удаляйте неизвестные объекты, чужие GMS или пользовательские рисунки.
- Исторические unknown/retained GMS не разрешаются новым кодом/VBE. До обновления используйте прежний релиз/оператора для подтверждения исхода; pre-upgrade проверка ничего не повторяет и не стирает. Старые отчёты и safety barrier сохраняются.
- Save As/export заменяет назначение автоматически. Export публикуется через промежуточный файл; нативный SaveAs не обещает атомарности. Отчёты и артефакты могут содержать пользовательские данные; краткая диагностика выдаёт только allowlist полей.
