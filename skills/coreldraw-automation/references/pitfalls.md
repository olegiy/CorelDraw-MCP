# Подводные камни API 27

- `Shape.Intersect` и `Shape.Duplicate` возвращают новый объект; сохраняйте его ссылку до чтения `StaticID`.
- `ConvertToCurves` изменяет shape на месте, поэтому после вызова читайте `shape.Curve` заново.
- `StaticID` стабилен в течение жизни shape, но не является глобальным идентификатором между документами.
- `SelectionRange` следует читать после проверки `Count`; пример перемещения не создаёт и не выбирает чужие объекты.
- Группы и вложенные группы нужно обходить рекурсивно, а слои — через `Page.Layers`.
- JSON из VBA должен использовать точку как десятичный разделитель и экранировать кавычки, слеши и переводы строк.
- Операции примеров создают только собственные фигуры; существующие пользовательские объекты не меняются.
